# 🦠 COVID-19 Death Prediction Project

This project aims to build a machine learning model that predicts the number of deaths due to COVID-19 based on various features from publicly available datasets.

---

## 📁 Project Structure  

```
COVID-19 Project/  
    ├── data/ # Datasets from Kaggle or other sources
    ├── notebooks/ # Jupyter notebooks for EDA & prototyping  
    ├── src/ # Source code for data processing and modeling  
    ├── models/ # Trained model files  
    ├── tests/ # Unit tests  
    ├── README.md # This file  
    ├── requirements.txt # List of Python packages  
    └── main.py # Entry point to run the project 
```

---

## 📊 Dataset

- **Source**: [Kaggle COVID-19 Dataset](https://www.kaggle.com/datasets/dhruvildave/covid19-deaths-dataset)
- **Contains**: Country-wise data on cases, deaths, recoveries, testing, etc.

---

## 🧠 Technologies Used

- Matplotlib / Seaborn
